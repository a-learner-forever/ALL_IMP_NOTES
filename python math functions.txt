Function	Description	Example

math.sqrt(x)	Square root	math.sqrt(25) → 5.0

math.pow(x, y)	Raises x to power y	math.pow(2,3) → 8.0

math.ceil(x)	Rounds up	math.ceil(4.2) → 5

math.floor(x)	Rounds down	math.floor(4.8) → 4

math.factorial(n)	Finds factorial	math.factorial(5) → 120

math.fabs(x)	Absolute value	math.fabs(-8) → 8.0

math.gcd(a, b)	Greatest Common Divisor	math.gcd(12,18) → 6

math.lcm(a, b)	Least Common Multiple	math.lcm(12,18) → 36

math.trunc(x)	Removes decimal part	math.trunc(7.89) → 7

math.remainder(x, y)	Remainder after division	math.remainder(10,3) → 1.0
